Principle

We should be able to inspect what trained the systems that influence us. Open weights alone are not enough — a TTLLM publishes the skeleton: data path, training code, checkpoints, metrics, and human-viewable provenance (ttlink).

Free public core

  • Weights, data, checkpoints, training code
  • Public stream of real process artefacts
  • ttlink — outputs linked to sources
  • Cryptographic manifests anyone can re-verify

Never paywalled. Paid layers buy reliability and service — not the bone.

Commercial outer layers

Reliability, compliance, convenience — never a paywall on the skeleton. See commercial/BOUNDARY.md in the repo.
