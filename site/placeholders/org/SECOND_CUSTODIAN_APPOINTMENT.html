Second custodian appointment — full example instrument

Written by Grok - Human checking required
Founder voice. Hard gate T9 — requires a real human to accept.
Until signed, ASSET_INVENTORY backup cells remain unnamed tombstones.

1. Why this exists (ethos)

Single-human concentration over domains, Cloudflare, GitHub, and claim language is a public integrity risk. Topology optimisation of the org means load paths for succession — not hope. The free public core survives in git even if the founder is unavailable; operations (DNS, deploys, incident comms) need a named backup.

2. Appointment text (example)

I, [Founder legal name], operational contact md@0265.au, appoint [SECOND CUSTODIAN FULL LEGAL NAME] (“Backup”) as second custodian for TTLLM continuity assets listed in continuity/ASSET_INVENTORY.md and any successor inventory.

3. Authority granted

On founder unavailability ≥30 days, written handoff, or Domain 1 emergency decision, Backup may:

  1. Deploy Cloudflare Pages project ttllms from public git main
  2. Administer DNS for ttllms.com / ttllms.org only to restore public site availability per existing BOUNDARY (no close-core changes)
  3. Administer GitHub maintainership for mattdale-creator/daisychainrrr for security and release integrity
  4. Publish Domain 5 integrity notices and status tombstones
  5. Coordinate with counsel on Entity matters if Entity exists

Explicitly not granted

  • Unilateral free-core closure or paywall of verification
  • Solo invention of production signing keys bypassing ceremony policy
  • Execution of side letters contradicting BOUNDARY
  • Silent suppression of High+ integrity findings
