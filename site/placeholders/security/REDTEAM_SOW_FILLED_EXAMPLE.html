2. Background (ethos)

TTLLM free public core is designed so strangers can re-hash truth. That only works if the transparency layer is attacked with the same seriousness as the model. This engagement is constructive QA, not vandalism theater and not a bounty-to-silence program.

3. Scope

In scope

  1. Free-core integrity: manifests, Merkle seals, signatures, seal freshness discipline
  2. Stream hash-chain integrity and tip publication honesty
  3. ttlink: index poison, canary presence/absence, QueryGuard bypass that enables destructive bulk harm
  4. Public claim honesty (eval packs vs marketing)
  5. Commercial isolation failures that risk free-core contamination or paywalled verify
  6. Process: decision log gaps, Boundary theater, disclosure clock failures

Out of scope

  • Closing free core as a deliverable
  • Extortion
  • Illegal content operations
  • Attacks on third parties unrelated to TTLLM
  • Accessing private tenant data beyond proving isolation failure (then stop and report)
