# 10-Year Financial Model (order-of-magnitude)

From founding conversation math; planning ranges, not promises.

## Costs

| Item | Range |
|------|-------|
| Serious 32B-class full open run (incl. experiments) | ~$4–8M per generation |
| Smaller 7–13B | low $100k–low $Ms |
| Storage + index (50–150 TB working set) | ~$0.4k–2.5k+/mo object storage + index serving |
| ttlink serving | ~few $k/mo public tier |
| Bandwidth | variable spike risk |

## Revenue shape

- Free core: high fixed cost, low marginal cost, marketing + trust infrastructure  
- Enterprise contracts: ~$50k–300k+/yr each (hosted SLA, audit, certified fine-tunes, TaaS)  
- Handful of contracts cover ongoing burn + fund next training run  

## 10-year sketch (illustrative)

Years 0–2: raise/fund first runs + free-core infra; publish founding artefacts; 0–5 enterprise  
Years 3–5: multi-generation models; TaaS and audit products; 10–40 enterprise  
Years 6–10: methodology licensing + multi-model portfolio; core still free  

Discipline: never close the core to hit a quarter.
