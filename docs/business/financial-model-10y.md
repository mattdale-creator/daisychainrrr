# 10-year financial model (founding conversation turn 19 + operational ledger)

## Core assumptions (explicit)
- Major 32B-class fully transparent training runs: ~$5–7M every 18–24 months (re-quote before fundraise)
- Public infrastructure (storage, ttlink, basic serving): starts ~$120k/year and scales
- Team grows to ~35–50 peak in base case
- Free core never directly monetised
- Red-team and integrity costs are first-class line items

## Scenarios
- **Conservative:** ~55–65% of base revenue Y10; profit later
- **Optimistic:** 1.6–1.9× base if TTLLM becomes recognised standard
- **Constrained:** maintain free core + nano/public skeleton; delay large training

## Drivers that must work
1. Trust compounds via free public TTLLM + verifiable ttlinks  
2. Enterprises pay for reliability/compliance on open foundation  
3. Discipline never closes core  
4. Training efficiency  
5. Red-team costs stay material but controlled
