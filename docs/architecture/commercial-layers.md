# Commercial Layers

Sit **outside** the free core. Full list and financial framing: `docs/business/`.

| Layer | Customer pays for | Must not hide |
|-------|-------------------|---------------|
| Hosted / managed inference | SLA, capacity, networking | Public model + data identity |
| Enterprise ttlink / audit | Retention, exports, SSO, higher limits | Core linking method for public models |
| Transparency-as-a-service | Helping others meet the standard | — |
| Certified fine-tunes | Support + indemnification | Inheritance of transparency guarantees |
| Analysis products | UX and compute on public stream | Public stream availability |
| Methodology licensing | Training teams | Specs remain public |
