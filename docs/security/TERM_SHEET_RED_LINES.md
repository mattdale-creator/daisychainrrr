# Fundraising / term-sheet red lines (BOUNDARY-safe)

**Updated:** 2026-08-08  
**Status:** Pre-entity operational policy — not legal advice  
**Precedence:** `commercial/BOUNDARY.md` > commercial convenience > revenue

## Must refuse (close-core)
Any term that:
1. Paywalls verification of a public-core claim
2. Requires privatising already-public weights, data cards, train code, basic ttlink, manifests, or public stream
3. Grants exclusive control to remove public artefacts without Domain 3 process
4. Forces silent alteration of public indexes/manifests for a customer or investor
5. Side letter that contradicts public BOUNDARY or decision log

## Must preserve
1. Free public core remains free and public
2. Domain 1 material decisions stay public (≤7 days)
3. High/Critical integrity incidents disclose on Domain 5 clocks
4. Demo keys ≠ production roots of trust; production keys multi-party after entity

## Allowed commercial (outside core)
Hosted SLA, VPC, enterprise audit tooling, certified fine-tunes with **published lineage**, priority support, methodology licensing, private customer data.

## Before any pitch
1. Attach or link public BOUNDARY
2. State nano ≠ scale honesty
3. List human gates still open
4. No “we will close the core later” narrative
