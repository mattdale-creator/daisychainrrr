# Red-Team Standard (summary)

Full publication rules: `docs/specs/10-red-team-publication.md` and `docs/specs/05-incident-disclosure.md`.

- Frontier-level pressure on model **and** ttlink/provenance systems  
- Default publish significant findings with severity, remediation, residual risk  
- Temporary withhold of exploit detail only under pre-committed exemptions  
- Findings cryptographically linked to affected artefact versions
