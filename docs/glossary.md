# Glossary

| Term | Meaning |
|------|---------|
| **TTLLM** | Totally Transparent Large Language Model — full stack openness, not open-weights alone |
| **Down to the bone / binary** | Radical structural honesty; delete soft tissue until only load-bearing structure remains |
| **Soft tissue** | Narrative, polish, selective disclosure, aesthetics that hide structure |
| **ttlink** | System linking model outputs to training sources, checkpoints, decision traces in human-viewable form |
| **Free public core** | Non-monetised skeleton: model artefacts, stream, basic ttlink, public decisions |
| **Commercial layer** | Paid reliability/compliance/convenience sitting *outside* the free core |
| **Matrix surface** | Cultural visual of cascading code; legitimate only when backed by real ttlinks |
| **Merkle manifest** | Content-hash leaf list + root binding a release set |
| **Proof RIP** | Device-capture + metadata seal of the founding SuperGrok session |
| **Founding conversation** | SuperGrok Heavy thread that defined the project (2026-08-07) |
| **FMTI** | Foundation Model Transparency Index (Stanford) |
| **OLMo / OLMoTrace** | Ai2 prior art for full-stack openness + output→data linking |
| **LLM360** | Prior art emphasising dense intermediate checkpoints |
