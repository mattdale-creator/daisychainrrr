# Dead-man / succession procedure (operational draft)

**Problem:** Single-human concentration (founder) is public and PARTIAL on ASSET_INVENTORY.

## If founder unavailable ≥30 days
1. **Public git** remains source of free-core bone — clones continue.
2. Backup custodian (when named) uses documented recovery for:
   - Cloudflare Pages deploy
   - Domain registrar/DNS
   - GitHub org ownership
   - Contact mailbox
3. Do **not** invent new production signing keys alone — ceremony policy (wall 6).
4. File Domain 1 decision for any emergency change of control.
5. Status page: honest “continuity event” note.

## Until second custodian named
- All “Backup” cells remain `*unnamed — TOMBSTONE*`
- Priority human action: pick backup + share recovery pack offline
- Optional: attorney escrow of recovery instructions

## Not a substitute for entity
Legal authority still needs wall 5 for contracts and bank.
