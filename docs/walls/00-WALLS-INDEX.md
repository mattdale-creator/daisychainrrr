# The wall — index (honest)

**Updated:** 2026-08-08  
**Meaning:** A *wall* is something an agent **cannot complete alone** (dashboard permission, legal filing, capital, second human, or revenue).  
It is **not** permission to leave the surrounding bone empty.

## Standing order (what “everything covered until the wall” means)

Until the founder says otherwise, default work is:

1. Build every free-core artefact and procedure that does **not** require fake powers.
2. For each wall item, still ship **max agent-doable depth** (scripts, runbooks, schemas, dry-runs, probes, status honesty).
3. **Never** claim the wall is closed without evidence.
4. Update the public site when status/bone changes (Pages deploy → **ttllms.com** when custom domain is attached).

“Standing orders” = do not wait to be re-asked to keep going on that loop.

## Wall vs soft tissue

| Soft tissue (forbidden) | Wall (honest) |
|-------------------------|---------------|
| “DNS done” when org does not resolve | “DNS script ready; org CNAME still needs Zone DNS Edit” |
| “Company formed” without entity | “Formation checklist + draft covenant; counsel required” |
| “CI green on GitHub” without workflow scope | “verify.yml on disk; PAT needs workflow scope to publish” |
