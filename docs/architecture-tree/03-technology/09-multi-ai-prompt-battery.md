## Summary

Run the same strategic prompts across multiple models/reviewers; compare divergences. Used for transparency domain design and self-audit (remember you're on drugs).

## Why (ethos)

Single-model monoculture is soft tissue epistemology.

## Prerequisites

- Access to ≥2 model families or human reviewers

## What to do (executable instructions)

1. Maintain prompt battery files under docs or architecture-tree (domain battery + strategy battery).
2. Run on major decisions: definition changes, safety claims, financial OOM, BOUNDARY changes.
3. Store anonymised outputs and synthesis; publish when non-sensitive.
4. Do not average into mush — surface disagreements.
5. Re-run when models update.
