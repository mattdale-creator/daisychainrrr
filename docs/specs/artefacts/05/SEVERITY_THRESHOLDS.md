# Incident severity thresholds

| Level | Examples | Disclosure |
|-------|----------|------------|
| Critical | Manifest forge, key compromise, index poison of public core | 72h ack + Domain 5/10 |
| High | Significant public-core integrity or availability failure | 72h ack |
| Medium | Partial degradations, non-critical bugs in proof surfaces | Register + periodic |
| Low | Cosmetic, no integrity impact | Optional batch |

Transparency-system failures use the same ladder as model failures.
