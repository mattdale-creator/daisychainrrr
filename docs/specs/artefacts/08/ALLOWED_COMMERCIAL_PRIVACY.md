# Allowed commercial privacy — Domain 8

Privacy **outside** free core is allowed for:

1. Customer prompts and private documents  
2. Customer VPC configs and tenant secrets  
3. Private commercial fine-tune weights **only if** lineage to public core is published and customer-private data is not laundered into silent public-core claims  
4. Non-core HR below influence thresholds (bands still public per Domain 6 when payroll exists)  
5. Proprietary UX/ops that does not gate core verification  
6. Contract pricing negotiations  
7. Internal commercial metrics not used as public capability claims  

## Test
“Can a stranger re-verify free-core claims with only public git + free tools, unpaid?”  
If **no** → not allowed privacy; it is prohibited opacity.
