# Boundary change process — Domain 8

## Rule
Any movement of an artefact from **public free core → private commercial privacy** is a material Domain 1 decision and requires updated BOUNDARY **before** implementation.

## Steps
1. Propose change with: artefact, direction (public→private or private→public), customer/revenue pressure note, residual risk.  
2. Boundary Custodian review against Allowed / Prohibited lists (`commercial/BOUNDARY.md`).  
3. Domain 1 decision within 7 days (public log).  
4. Update `commercial/BOUNDARY.md` + `docs/specs/artefacts/08/*`.  
5. Public stream event optional; scorecard Domain 8 note required.  
6. Re-train sales/partners; refuse path still active for close-core asks.  

## Forbidden shortcuts
- Side letter  
- Soft-launch paid exclusive weights  
- Quiet README rewrite without log
