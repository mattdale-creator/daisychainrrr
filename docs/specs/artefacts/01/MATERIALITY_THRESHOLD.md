# Materiality threshold — Domain 1

**In force:** 2026-08-08

A decision is **material** (must enter Decision Log within 7 days) if it affects any of:

1. Free public core (weights, data, checkpoints, code, basic ttlink, manifests, public stream)
2. BOUNDARY between free core and commercial layers
3. Training runs above hobby scale (any run intended for public TTLLM branding)
4. Transparency policy, domain specs, or scorecard standards
5. Ownership, funding, influence rights, or legal form of the project
6. Domains, DNS, hosting, or signing keys that underwrite public proof
7. Response to legal demands, security incidents, or red-team findings above Low
8. Hiring for roles with release or security authority

## Non-material (still may log)
Routine dependency bumps, typo fixes, internal notes with no public claim impact.

## Disputes
If unclear, log it. Soft tissue thrives in "probably not material."
