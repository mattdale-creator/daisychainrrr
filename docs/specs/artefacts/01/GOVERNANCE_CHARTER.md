# Governance Charter — TTLLM / daisychainrrr

**Version:** 0.1.0  
**Status:** In force for project operations (pre-entity)  
**Ethos:** Down to the bone. Commercial features may never require the public core to become opaque.

## Decision rights (pre-entity)
- **Founder / project lead (md@0265.au):** material decisions affecting free core, BOUNDARY, releases, domains, capital.
- **Decision Log:** all material decisions within 7 days (Domain 1).
- **Default public:** material decisions public unless time-limited exception is logged.

## Materiality threshold
Must log: model training priorities; data inclusion/exclusion; commercial feature boundaries; compute above hobby threshold; changes to transparency policy; responses to external legal/security pressure; domain/DNS/infra that affects public proof.

## Dissent
Minority views recorded without consensus theatre when raised in writing to the Decision Log.

## Precedence
BOUNDARY Specification and free public core take precedence over commercial convenience.
