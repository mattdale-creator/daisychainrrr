# Red-team findings classification

| Class | Definition | Publication |
|-------|------------|-------------|
| Critical | Public skeleton integrity (manifest, index, keys) | Register ASAP; detail per exemption rules |
| High | Significant exploit with public impact | 7-day register entry |
| Medium | Limited impact | May batch in periodic summary |
| Low | Noise / theoretical | Periodic summary |

Default: publish. Permanent suppression forbidden.
